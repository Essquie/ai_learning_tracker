Prompt structure checklist

Tip: change one meaningful variable at a time. If you change the prompt, model and temperature together, you won't know what caused the result.

Reusable starter prompt

TASK\nClassify the supplied support ticket.\n\nALLOWED CATEGORIES\nBILLING, TECHNICAL, ACCOUNT, OTHER\n\nALLOWED PRIORITIES\nLOW, MEDIUM, HIGH, URGENT, UNKNOWN\n\nRULES\n- Use only evidence in the ticket.\n- Do not invent missing information.\n- If evidence is insufficient, use UNKNOWN where allowed.\n- Keep the summary under 30 words.\n- Return only the requested structured fields.\n\nINPUT\n{{ticket_text}}\n\nOUTPUT FIELDS\ncategory, priority, summary, needs_human_review

Reference library

Prioritise official documentation and primary learning material. Links open in a new tab. Follow selected chapters instead of attempting every course in full before the deadline.

Course scope note: The full Hugging Face LLM Course is broader than this 9-week plan and states that Python knowledge is helpful/required. Use the introductory transformer and tokenizer material to strengthen conceptual understanding; deeper Python, model training and fine-tuning are longer-term goals, not prerequisites for demonstrating applied AI engineering with Java.

How to keep the plan realistic

One hour is a strict budget. Focus on outputs rather than consuming every resource.

Daily 60-minute split

10 min: recall yesterday.
20 min: learn one concept.
25 min: code or run an experiment.
5 min: note outcome and next action.

What counts as done?

A working code sample, solved problem, tested endpoint, saved prompt experiment, or written explanation. A video watched by itself is not completion.

When you're behind

Use the weekly catch-up day. Drop optional reading before dropping coding, evaluation, or interview practice. Leave advanced fine-tuning for after the deadline.
